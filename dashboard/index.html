    Read this before farming

    “Pre-token” means the protocol's record carries no token — no market cap, no CoinGecko id, no symbol — not that it has promised one. Implied value is a ranking model, not a price prediction: it says which launch would be biggest if it happened, not that it will happen or what a token would trade at. Airdrops are never guaranteed, claims never ask you to pay, and the farm plans above are starting points, not advice. Verify every link on the protocol's own site before you connect a wallet.
